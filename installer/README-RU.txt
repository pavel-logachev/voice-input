VOICE INPUT 0.5.1

Полностью локальная русская диктовка для Windows 10/11.

После установки:
1. Voice Input запустится в системном трее.
2. Удерживайте Ctrl + Shift + Space в любом обычном текстовом поле.
3. Произнесите фразу и отпустите клавиши.
4. Нажмите Esc во время диктовки, чтобы отменить её без вставки текста.

Запись без удержания клавиш:
1. Нажмите Ctrl + Shift + K, чтобы начать запись.
2. Нажмите Ctrl + Shift + K повторно, чтобы закончить запись и вставить текст.

Если клавиатура поддерживает переназначение клавиш, удобную дополнительную кнопку можно настроить на Ctrl + Shift + K в программе её производителя.

Обычный запуск проходит тихо. Системное уведомление появляется только при ошибке, требующей внимания. Текущий статус и сочетания клавиш доступны в меню значка Voice Input в трее.

Во время записи линия в окне Voice Input реагирует на голос движущимися полосами. При тишине она остаётся ровной. На Windows 11 при включённых эффектах фон карточки мягко размывается; на Windows 10 или если прозрачность недоступна автоматически используется контрастная тёмная подложка.

Модель GigaAM и native runtime уже включены в установщик. Первый запуск только проверяет их контрольные суммы и распаковывает runtime; подключение к интернету для распознавания не требуется.

Конфиденциальность:
- распознавание выполняется локально;
- аудио обрабатывается в памяти и по умолчанию не сохраняется;
- история расшифровок не ведётся;
- диагностика не включена по умолчанию.

Ограничения версии 0.5.1:
- используется микрофон Windows по умолчанию;
- горячие клавиши пока фиксированы;
- вставка в приложения, запущенные от администратора, из обычного Voice Input блокируется Windows;
- установщик пока не подписан коммерческим сертификатом, поэтому Windows SmartScreen может показать предупреждение издателя.
