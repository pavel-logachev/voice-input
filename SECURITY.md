# Политика безопасности

## Поддерживаемый релиз

Исправления безопасности вносятся в текущую линию релизов `1.0.x` и в `main`. Версии 0.x не поддерживаются.

## Как сообщить

Используйте **приватное сообщение об уязвимости** GitHub: вкладка «Security» репозитория, кнопка «Report a vulnerability». Если этот канал недоступен, напишите на `ai@logachev.net`.

Не прикладывайте API-ключ OpenAI, записи голоса и текст диктовок. Не создавайте публичные issue с ключами и подробностями рабочих эксплойтов.

## Границы безопасности

- Звук уходит только в OpenAI и только в момент диктовки; на диск запись не сохраняется.
- API-ключ хранится в `%LOCALAPPDATA%\VoiceInput\secrets`, зашифрован через Windows DPAPI для учётной записи пользователя и передаётся только как заголовок авторизации запроса к OpenAI.
- История расшифровок не ведётся, телеметрии нет.
- Диагностический файл включается только переменной `VOICE_INPUT_DIAGNOSTIC_LOG` и не содержит ни звука, ни текста.
- Установщик не требует прав администратора и пока не подписан сертификатом: сверяйте SHA-256 файла со значением на странице релиза.
- Приложение вставляет текст в активное окно от имени обычного пользователя и не работает с окнами, запущенными от администратора.
