# Политика безопасности

## Поддерживаемый релиз

Исправления безопасности вносятся в текущую линию релизов `1.x` и в `main`. Версии 0.x не поддерживаются.

## Как сообщить

Используйте **приватное сообщение об уязвимости** GitHub: вкладка «Security» репозитория, кнопка «Report a vulnerability». Если этот канал недоступен, напишите на `pavel@logachev.net`.

Не прикладывайте API-ключи (OpenAI и своего сервера), записи голоса и текст диктовок. Не создавайте публичные issue с ключами и подробностями рабочих эксплойтов.

## Границы безопасности

- Куда уходит звук, зависит от движка распознавания, выбранного в настройках. С движком «OpenAI, через интернет» звук уходит в OpenAI и только в момент диктовки. С движком «На этом компьютере (GigaAM)» звук не покидает компьютер. С движком «Свой сервер» звук уходит только на сервер, указанный в настройках. На диск запись не сохраняется.
- API-ключ OpenAI хранится в `%LOCALAPPDATA%\VoiceInput\secrets`, зашифрован через Windows DPAPI для учетной записи пользователя и передается только как заголовок авторизации запроса к OpenAI.
- Ключ своего сервера необязателен. Он тоже зашифрован DPAPI, хранится отдельно от ключа OpenAI, не попадает в `settings.json` и передается только как заголовок авторизации запроса к указанному серверу. Адрес с `http` разрешен только для этого компьютера и локальной сети, для остальных адресов нужен `https`. Автоматические перенаправления для своего сервера отключены.
- Модель для локального движка загружается из настроек с Hugging Face (`handy-computer/gigaam-v3-e2e-rnnt-gguf`) и после загрузки проверяется по SHA-256.
- История расшифровок не ведется, телеметрии нет.
- Диагностический файл включается только переменной `VOICE_INPUT_DIAGNOSTIC_LOG` и не содержит ни звука, ни текста диктовок, ни ключей.
- Журнал сбоев `%LOCALAPPDATA%\VoiceInput\logs\crash.log` содержит время, версию, тип ошибки и место в коде — без текста сообщений, диктовок и ключей.
- Установщик не требует прав администратора и пока не подписан сертификатом: сверяйте SHA-256 файла со значением на странице релиза.
- Приложение вставляет текст в активное окно от имени обычного пользователя и не работает с окнами, запущенными от администратора.
