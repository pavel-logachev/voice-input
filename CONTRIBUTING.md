# Как участвовать

Voice Input: небольшое самостоятельное приложение. Репозиторий принимает точечные сообщения об ошибках и воспроизводимые исправления.

## Прежде чем открывать issue

- Уберите из скриншотов и журналов API-ключ и текст диктовок.
- Укажите версию Windows, версию Voice Input (видна в окне настроек), микрофон и приложение, в которое шла вставка.
- Опишите точные шаги: что нажали, что сказали, что появилось в оверлее и в поле ввода.
- Если текст не вставился, напишите, запущено ли целевое приложение от администратора.

## Локальная проверка

Нужны Windows 10/11 x64 и .NET 10 SDK.

```bash
dotnet build VoiceInput.sln -c Release
dotnet test VoiceInput.sln -c Release --no-build
```

Настоящие окна можно отрисовать в PNG без записи речи:

```bash
dotnet run --project tests/VoiceInput.UiPreview -c Release -- preview
```

Делайте изменения узкими и добавляйте регрессионный тест, когда меняется поведение. О проблемах безопасности сообщайте закрыто, как описано в [SECURITY.md](SECURITY.md).
