Architecture draft 0.2 · local-first

Voice Input

Нативный Windows-путь: hotkey → аудио → локальный GigaAM → безопасная вставка в сохранённое поле.

Risk first

Сначала доказываем захват target, сохранение фокуса и вставку fake-текста. ASR подключается только после надёжного системного пути.

Predictable by default

Verbatim — основной режим. Никакого обязательного LLM-rewrite, фоновой записи или неожиданной поздней вставки.

Private by default

Аудио не пишется на диск и не уходит в сеть, история выключена, secure fields блокируются, модель проверяется по checksum.
