# Voice Input

Нативное Windows-приложение для диктовки в любое активное поле ввода по глобальной горячей клавише.

## Статус

Сейчас зафиксирована архитектурная концепция. Реализация ещё не начата.

- [Архитектурное видение](docs/ARCHITECTURE.md)
- [Исследование локальных ASR-моделей](docs/MODEL_RESEARCH.md)
- [Визуальная схема](docs/architecture.html)

## Предварительные принципы

- приложение не забирает фокус у окна, в которое пользователь диктует;
- запись вызывается глобальной клавишей в любом приложении;
- распознавание — local-first; основной кандидат — GigaAM-v3 через сменный provider interface;
- текст вставляется через несколько стратегий с проверяемым fallback;
- аудио не сохраняется и не покидает компьютер, история текста по умолчанию выключена;
- никакого обязательного «улучшения текста» через LLM: дословный и редакторский режимы разделены.
