# Voice Input

**Диктуйте в поля ввода Windows: зажмите `Ctrl + Shift + Space`, скажите фразу и отпустите клавиши — текст появится у курсора.**

[Скачать](https://github.com/pavel-logachev/voice-input/releases/latest) · [Как пользоваться](<#как-пользоваться>) · [Приватность](<#приватность>) · [Архитектура](<docs/ARCHITECTURE.md>)

Версия 1.0.0 · Windows 10 1809+ / 11 x64 · [MIT](<LICENSE>)

Voice Input работает в системном трее. Речь распознаёт OpenAI по вашему API-ключу: нужен интернет, запросы оплачиваются с вашего аккаунта OpenAI.

Первый запуск — [установить приложение и сохранить API-ключ в настройках](<#установка>).

## Как пользоваться

1. **Поставьте курсор** в нужное поле: в мессенджере, почте, браузере или редакторе кода.
2. **Зажмите `Ctrl + Shift + Space` и говорите.** Пока клавиши зажаты, идёт запись.
3. **Отпустите клавиши.** Дождитесь распознавания — текст появится в поле у курсора.

Для записи без удержания используйте `Ctrl + Shift + K`: первое нажатие начинает запись, повторное — завершает.

Чтобы отменить запись или распознавание, нажмите `Esc`: текст не вставится, даже если ответ придёт позже.

## Что предусмотрено

- **Видно, что происходит.** Оверлей показывает этап диктовки, таймер и уровень голоса, не забирая фокус. Поддерживается высокая контрастность.
- **Проверка окна перед вставкой.** Если активно другое окно, текст не вставляется.
- **Восстановление буфера обмена.** После вставки возвращается прежнее содержимое, если за это время оно не изменилось.
- **До 10 минут на запись.** На лимите запись останавливается, сказанное распознаётся и вставляется.
- **Обработка потери микрофона.** Если его отключили во время записи, приложение сообщает об ошибке и ничего не вставляет.
- **Понятные причины ошибок.** Неверный ключ, исчерпанный лимит или баланс OpenAI, отсутствие сети, недоступность сервиса.
- **Конфликт клавиш не мешает запуску.** Если одно сочетание занято другой программой, приложение сообщает об этом и работает со вторым.
- **Один экземпляр приложения.** Повторный запуск не создаёт вторую копию.

## Настройки

Откройте настройки двойным щелчком по значку Voice Input в трее.

- **API-ключ OpenAI:** добавьте или замените ключ кнопкой «Сохранить». Доступны «Проверить» и «Удалить ключ»; после сохранения проверка запускается автоматически.
- **Язык речи:** «Определять автоматически», «Русский», «English», «Українська» или «Deutsch» — подсказка для облачного распознавания.
- **Микрофон:** конкретное устройство или «По умолчанию в Windows». Новый выбор применяется со следующей записи.
- **Автозапуск:** «Запускать вместе с Windows».

Микрофон можно сменить и из меню трея. Если выбранное устройство не подключено к началу записи, используется микрофон Windows по умолчанию.

## Установка

Нужны Windows 10 1809+ / 11 x64, микрофон, интернет и собственный API-ключ OpenAI. Распознавание оплачивается с вашего аккаунта OpenAI.

1. Откройте [последний релиз](https://github.com/pavel-logachev/voice-input/releases/latest) и скачайте `VoiceInput-Setup-1.0.0.exe`.
2. Запустите установщик. Права администратора не нужны. Установщик пока не подписан сертификатом, поэтому Windows SmartScreen может предупредить о неизвестном издателе.
3. При первом запуске откроется окно настроек. Вставьте API-ключ OpenAI (начинается с `sk-`) и нажмите «Сохранить» — ключ сразу проверится.
4. Поставьте курсор в любое поле ввода и зажмите `Ctrl + Shift + Space`.

Перед запуском установщика сверьте его SHA-256 со значением на странице релиза.

При обновлении с 0.9.x устанавливайте новую версию поверх старой: ключ и настройки сохранятся. При удалении программы ключ удаляется вместе с ней.

## Приватность

- **Запись — только для диктовки.** Звук хранится в памяти и не сохраняется на диск.
- **Распознавание — в OpenAI.** После окончания записи звук отправляется в OpenAI; условия обработки определяет ваш договор с OpenAI.
- **Ключ зашифрован.** По умолчанию он хранится в `%LOCALAPPDATA%\VoiceInput\secrets`, защищённый Windows DPAPI для вашей учётной записи. В OpenAI передаётся только как заголовок авторизации запроса.
- **Без истории и телеметрии.** Voice Input не ведёт историю расшифровок и не собирает телеметрию.
- **Диагностика — по запросу.** Журнал включается только переменной `VOICE_INPUT_DIAGNOSTIC_LOG` и не содержит ни звука, ни текста диктовок.

## Как это работает

Voice Input написан на .NET 10 и WPF. При начале диктовки приложение запоминает активное окно и записывает звук через WASAPI в память: моно, 16 кГц.

После остановки записи звук отправляется в OpenAI в формате WAV PCM16, модель — `gpt-transcribe`. Перед вставкой приложение проверяет активное окно: в стандартные поля Edit/RichEdit текст вставляется напрямую, в остальные — через буфер обмена с последующим восстановлением, если его содержимое не изменилось.

Подробнее — в разделе «Что изменилось в 1.0» в [архитектуре](<docs/ARCHITECTURE.md>).

## Запуск из исходников и проверка

Нужны Windows 10 1809+ / 11 x64 и .NET 10 SDK. Выполняйте команды из корня локальной копии репозитория.

Запуск приложения:

```bash
dotnet run --project src/VoiceInput.App -c Release
```

Сборка и тесты:

```bash
dotnet build VoiceInput.sln -c Release
dotnet test VoiceInput.sln -c Release --no-build
```

Автотесты проверяют диктовку и отмену, запись на подставном устройстве, клиент OpenAI, хранение ключа и настроек, горячие клавиши и вставку текста. [CI](https://github.com/pavel-logachev/voice-input/actions/workflows/ci.yml) собирает решение и запускает тесты на Windows при каждом push и pull request в `main`.

Отрисовка настоящих окон в PNG без записи речи:

```bash
dotnet run --project tests/VoiceInput.UiPreview -c Release -- preview
```

Для тестов и параллельных запусков предусмотрены переменные:

- `VOICE_INPUT_DATA_DIR` — папка настроек и ключа.
- `VOICE_INPUT_INSTANCE_NAME` — имя защиты от второго экземпляра.
- `VOICE_INPUT_DIAGNOSTIC_LOG` — путь к диагностическому журналу.

**Локальное распознавание доступно в сборке из исходников, но не в установщике 1.0.0.** Выбор «На этом компьютере (GigaAM)» появляется, если рядом с приложением есть `worker/VoiceInput.Asr.Worker.exe`. При первом включении загружаются runtime и модель — около 200 МБ, с проверкой SHA-256. После загрузки локальный движок работает офлайн, без ключа OpenAI.

## Ограничения

- В установщике 1.0.0 нет офлайн-режима: для диктовки нужны интернет и API-ключ OpenAI.
- Сочетания клавиш фиксированы, переназначить их в настройках нельзя.
- Windows блокирует вставку из обычного процесса в программы, запущенные от имени администратора.
- Приложение запоминает окно, а не конкретное поле: внутри того же окна текст попадёт туда, где курсор стоит в момент вставки.
- Автообновления и подписи кода пока нет.
