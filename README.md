# Voice Input

Нативное local-first приложение для Windows, которое по глобальной горячей клавише вставляет результат диктовки в активное поле ввода.

> **Текущий этап — Slice A.** Захват аудио и распознавание ещё не подключены. Прототип доказывает самый рискованный системный путь: global hotkey → сохранение target → неактивирующийся overlay → Unicode-вставка без clipboard.

## Что уже работает

- резидентное WPF-приложение и tray icon;
- глобальная комбинация `Ctrl + Shift + Space`;
- захват foreground `HWND` до появления overlay;
- overlay с `WS_EX_NOACTIVATE`, не забирающий фокус;
- ожидание отпускания клавиш-модификаторов;
- вставка тестовой фразы `Диктовка работает.` через Unicode `SendInput`;
- отмена вставки, если foreground window успело измениться;
- защита от параллельных hotkey-сессий;
- автоматический E2E harness для реальной проверки Windows-пути.

## Запуск прототипа

Требования: Windows 10/11 и .NET 10 SDK.

```bash
dotnet run --project src/VoiceInput.App -c Release
```

После запуска поставьте курсор в обычное поле ввода и нажмите `Ctrl + Shift + Space`. Завершение приложения — через пункт **«Выход»** в tray menu.

## Проверка

```bash
dotnet test VoiceInput.sln -c Release
```

Полный E2E-тест запускается при уже работающем `VoiceInput.App`:

```bash
dotnet run --project tests/VoiceInput.E2E.Harness -c Release
```

Harness на несколько секунд открывает собственное поле ввода, посылает глобальную горячую клавишу, проверяет фактически вставленный русский текст и восстанавливает прежнее foreground window.

## Следующий вертикальный срез

1. WASAPI-захват mono PCM в памяти.

4. GigaAM-v3 E2E RNNT Q4 через `transcribe.cpp`.
5. Подмена тестовой фразы реальной локальной расшифровкой.

## Принципы

- приложение не забирает фокус у окна, в которое пользователь диктует;
- распознавание — local-first; основной кандидат — GigaAM-v3;
- аудио не сохраняется и не покидает компьютер;
- история текста по умолчанию выключена;
- LLM-редактура не является обязательным этапом;
- дословный и редакторский режимы остаются раздельными.
